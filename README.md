# Utility.GUI

**Utility.GUI** is a powerful, lightweight **bookmarklet** designed to inject a suite of handy everyday tools directly into any webpage. With a single click, it opens a sleek graphical user interface (GUI) packed with utilities to enhance your browsing, automation, and productivity.

Since it runs entirely as a bookmarklet, there is **no installation, no browser extension required, and zero background resource usage**.

## 🚀 Key Features

* **Quick Launch:** Activate the GUI instantly from your browser's bookmarks bar on any website.
* **Browsing Utilities:** Take custom screenshots, enable auto-scrolling, force dark mode, or bypass text-selection restrictions.
* **Content Helpers:** Easily extract text, download page images, calculate numbers, or generate QR codes instantly.
* **Clean UI/UX:** A modern, draggable, and collapsible interface that stays out of your way until you need it.
* **100% Client-Side:** Fully secure and privacy-focused—your data never leaves your browser.

## 📦 How to Install & Use
1. **Get files:** Go to main and get the file (if you want as bookmarklet go to “utility-gui-bookmarklet.txt)
2. **Create a Bookmark:** Right-click your browser's Bookmarks Bar and select **Add Page** (or **New Bookmark**).
3. **Name It:** Set the name to `Utility.GUI`.
4. **Paste the URL:** Paste your minified bookmarklet code directly into the **URL / Location** field.
5. **Run it:** Navigate to any webpage and click your new `Utility.GUI` bookmark to launch the tool!
